1Qué hay en cada punto de Gauss

Cada punto trae cuatro números: ξᵢ (dónde), wᵢ (su peso = el ancho de su rectángulo), f(ξᵢ) (la altura) y wᵢ·f(ξᵢ) (lo que aporta).

2Las cuatro incógnitas, una barra cada una

4 incógnitas (ξ₁, ξ₂, w₁, w₂) → 4 condiciones:
c1 =   1∫−1  1 dξ = 2(f = 1 → w₁ + w₂ debe dar 2)
c2 =   1∫−1  ξ dξ = 0(f = ξ → w₁ξ₁ + w₂ξ₂ debe dar 0)
c3 =   1∫−1  ξ2 dξ = 23(f = ξ² → w₁ξ₁² + w₂ξ₂² debe dar 2/3)
c4 =   1∫−1  ξ3 dξ = 0(f = ξ³ → w₁ξ₁³ + w₂ξ₂³ debe dar 0)
